# Third-party components and notices

ReliefCart is designed as a patch on top of the official PayPal developer starter:
https://github.com/paypaldev/hackathon-paypal-ag-grid-boilerplate

It also uses the PayPal JavaScript SDK v6 / REST API, AG Grid / AG Studio, Channel3 product search API, Groq API and Supabase client. Review and comply with each provider's current terms, SDK licences, branding requirements and API policies before publishing.
